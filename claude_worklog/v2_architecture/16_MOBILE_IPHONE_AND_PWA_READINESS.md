# 16 Mobile, iPhone, and PWA Readiness

## Readiness objectives
- responsive web UX
- PWA readiness
- future iPhone app API compatibility
- mobile-safe approvals
- push notification readiness
- read-only mobile monitoring first

## Architectural constraints
- Critical/dangerous controls require explicit confirmation UX.
- Mobile default surface prioritizes monitoring and approvals, not high-risk direct trading controls.
- API contracts remain client-agnostic for future native app integration.
