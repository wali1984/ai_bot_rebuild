# Agent Operating Model

- VS Code/Copilot is bootstrap only.
- Claude Code is primary architecture/build agent.
- Codex is adversarial reviewer.
- Ollama is local summarizer/evidence compressor.
- Agent Supervisor runs approved tasks automatically.
- L0/L1/L2 safe rebuild tasks can run automatically.
- L3 may run only if policy-preapproved.
- L4/L5 require human approval.
- No live trading or old bot mutation.
- All agent actions logged.
