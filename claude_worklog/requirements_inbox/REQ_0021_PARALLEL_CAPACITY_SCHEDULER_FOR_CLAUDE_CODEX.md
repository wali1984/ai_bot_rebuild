# Requirement 0021 - Parallel Capacity Scheduler for Claude Code and Codex

## Objective

Use Claude Code Max 20x and Codex Pro/Max 20x capacity efficiently during every 5-hour window.

The system must stop underutilizing Codex while Claude is building.

## Target model

Claude Code:
- primary planner/builder
- one active build lane
- consolidated milestone tasks
- builds the current paper/backtest MVP milestone

Codex:
- parallel reviewer
- parallel autofixer
- parallel watchdog
- test hardener
- safety auditor
- evidence reconciliation fixer

Ollama:
- summarization and context compression
- no secrets

## Utilization goal

During active build periods:
- Claude Code should be used for current MVP implementation.
- Codex should be used continuously for review, autofix, diagnostics, and test hardening.
- Codex should not sit at 2-3% utilization while non-live work remains.

This is a utilization target, not permission to bypass safety.

## Scheduling rules

### If Claude child is active and Git is dirty

Codex may:
- review already committed artifacts
- run read-only diagnostics
- inspect status
- inspect committed docs/tests/code
- prepare recommendations

Codex may not:
- patch dirty files
- patch files likely being generated by Claude
- commit changes that race Claude output

### If Claude child is inactive and Git is clean

Codex may:
- autofix non-live blockers
- patch code/tests/docs
- run validation
- secret scan
- commit/push
- run re-review
- restart planner when safe

### If Claude child is inactive and Git is dirty

Codex must:
- classify dirty files
- restore runtime prompt noise
- archive no-progress planner notes
- validate generated task JSON
- remove END_FILE leakage
- recover safe path mismatches
- commit durable artifacts
- restart planner when clean

### If human_attention_required appears

Codex must:
- diagnose
- classify
- fix if non-live
- validate
- commit/push
- re-review
- continue

### If Codex FAIL marker appears

Codex must:
- create autofix
- patch
- validate
- commit/push
- re-review

## Hard forbidden actions

Codex and Claude may never:
- modify `/home/wali/Desktop/AI BOT`
- write/delete Redis keys
- restart live services
- place/cancel orders
- change leverage/margin
- enable live trading
- deploy
- run production migrations
- expose or commit secrets
- bypass final live approval
