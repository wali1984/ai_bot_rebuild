### Paper ledger integration

Blocked as MVP integration.

Evidence:
- `v2/backend/app/services/paper_execution_ledger/service.py:26-93` accepts a `RiskDecisionRecord`, maps risk reason codes to mirror ledger action/reason codes, and emits `PaperExecutionLedgerEntry(..., live_blocked=True)`.

- Harnesses such as `v2/backend/tests/unit/paper_mode_evidence_collection_harness/harness.py:37-62` and `v2/backend/tests/unit/historical_pnl_replay_wiring/harness.py:46-63` emit a flag and then assemble ledger/replay evidence, but the flag is asserted separately and is not an input to the ledger recorder.

Blocker:

## Concrete blockers

1. `PaperModeFlag` is not required by `assemble_risk_decision_record` or `build_risk_decision_evaluator`, so risk `allow` can be emitted without paper-mode evidence.
2. `PaperModeFlag` is not required by `assemble_paper_execution_ledger_entry` or `build_paper_execution_ledger_recorder`, so ledger records can be emitted without paper-mode evidence.
3. Paper-mode explainability fields are harness-level projections, not production composition output tied to the same flag that gates risk and ledger recording.
4. Focused tests could not be rerun in this shell because `pytest` is unavailable.

## Proposed non-live autofix tasks

1. Add a paper-mode evidence input to the risk gateway service/composition boundary, validate it is a `PaperModeFlag` with `live_blocked=True` and mode in `{paper, live_blocked}`, and fail closed before any `allow` if missing or invalid.
2. Add a paper-mode evidence input to the paper execution ledger service/composition boundary, or require a risk record that explicitly carries paper-mode fields, and add tests proving ledger recording fails without paper-mode evidence.
3. Add immutable paper-mode evidence fields to ledger/explainability output, such as `paper_mode_mode`, `paper_mode_live_blocked`, and a deterministic flag timestamp/reference, without introducing persistence or live execution.
4. Add a non-live end-to-end composition harness that emits one flag, feeds the same flag through orchestrator/risk/ledger/explainability, and asserts no Redis, exchange, FastAPI, scheduler, or live execution surfaces are imported or invoked.
5. Restore local dev-test tooling or document the expected `.venv` path so focused paper-mode MVP suites can be rerun in this workspace without dependency installation.
