# 2E3A Checkpoint Metadata Deprioritized

## Classification

The planner generated checkpoint metadata domain artifacts immediately after Phase 2E2.C worker health composition.

## Decision

These artifacts are not being dispatched now. Requirement 0017 redirects the roadmap to the shortest safe path toward non-live replay/backtest and paper trading MVP.

Checkpoint/model metadata remains allowed only when needed to identify validated prediction output. Broad checkpoint infrastructure should not precede:

- trainer prediction output MVP
- orchestrator decision MVP
- risk gateway default-deny MVP
- paper execution ledger MVP
- replay/backtest runner MVP
