## Why an addendum

The aggregate symbol-universe scoring service was already in place
when the user invoked
`V2_ALT_DATA_SYMBOL_UNIVERSE_SCORING_READY`. The remediation work in
this packet is a small set of additive field changes on top of that
existing service, enforced by 7 new regression tests. All other
behavior — including the aggregate `altdata_symbol_score` formula,
Redis allowlist, and the ranking sort key — is unchanged.

## New per-symbol score fields

`v2/backend/app/services/alternative_data/symbol_scoring_contract.py`
(`build_symbol_score_payload`)

| Field | Source / semantics |
| ----- | ------------------ |
| `altdata_symbol_rank` | 1-based rank from the candidates pass; back-filled onto the per-symbol payload after sort. Stays `None` until the candidates pass runs. |
| `missing_provider_flags` | Alias of `missing_reasons` matching the user-spec field name. |
| `stale_provider_flags` | Alias of `stale_reasons` matching the user-spec field name. |
| `nansen_key_present` | `True` iff the Nansen provider payload reports `key_present=True`. |
| `lunarcrush_key_present` | Same for LunarCrush. |
| `nansen_key_missing_no_network` | `True` iff Nansen `source_status == "KEY_MISSING_NO_NETWORK"`. |
| `lunarcrush_key_missing_no_network` | Same for LunarCrush. |
| `nansen_budget_limited` | `True` iff Nansen `source_status == "DAILY_BUDGET_EXHAUSTED"`. |
| `lunarcrush_budget_limited` | Same for LunarCrush. |

The operator dashboard can now distinguish "key absent" from
"budget exhausted" from "stale payload" without parsing free-form
`missing_reasons` strings.

## New candidates-payload field

`build_symbol_universe_candidates`:

- `altdata_symbol_rank_per_candidate: {symbol: rank}` — 1-based rank
  after sort. Each row's `altdata_symbol_rank` carries the same
  value, and the per-symbol score payload is back-filled.

## Sort key (unchanged)

1. Non-null `altdata_symbol_score` first
2. Higher `altdata_symbol_score`
3. Higher `provider_availability_score`
4. Higher `altdata_freshness_score`
5. Alphabetical symbol

## Degradation matrix

| Provider state | `provider_available` | Score impact | Aggregate score |
| -------------- | -------------------- | ------------ | --------------- |
| Provider payload absent | `False` | drops half the availability weight | computed from remaining provider only |
| `KEY_MISSING_NO_NETWORK` | `False` | same; explicit `*_key_missing_no_network=True` | same |
| `DAILY_BUDGET_EXHAUSTED` | `False` | same; explicit `*_budget_limited=True` | same |
| Payload age > `max_provider_age_seconds` | `False` | adds `*_payload_stale` to `stale_provider_flags` | same |
| Both providers missing | `{nansen: False, lunarcrush: False}` | `provider_availability_score=0.0` | `altdata_symbol_score=None`, `providers_consulted=[]` |

No provider state can override the strict paper-fill gate, authorize
live or canary, expand `live_symbols`, or silently expand
`paper_symbols`. `paper_symbols_expanded=False` is unconditional in
this packet.
