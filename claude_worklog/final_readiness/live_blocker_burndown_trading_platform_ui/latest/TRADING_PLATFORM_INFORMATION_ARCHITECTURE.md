
# Trading Platform Information Architecture

The website support lane is organized as a trading platform UI over runtime truth, not as the source of truth.

1. Trade Cockpit: Mission Control, Trading Terminal Preview, Paper Trading, Replay, Live Readiness.
2. Markets / CoinAnk Intelligence: Market Intelligence, Symbols, Liquidations, Funding, Open Interest, Long/Short, Radar / Screener.
3. AI / Strategy: Trainer Prediction Monitor, Signal Explainability, Signals, Strategy Admin, Trainer Admin, Orchestrator Admin.
4. Execution / Portfolio: Executions, Positions, Paper Ledger, Audit Ledger, Exchange Manager.
5. Risk / Safety: Risk Control, Kill Switch, External Position Quarantine, Config Admin, Live Gate.
6. System / Automation: Monitor Center, Script Registry, Coverage / System Atlas, Build / Validation, Claude Admin AI, Codex Review Center, Ollama Assistant.
7. Mobile / Future: Mobile / iPhone Readiness, PWA/iPhone API contract, alerts and approvals.

Runtime truth and safety win over UI presentation. Long proof artifacts stay in the Operator Proof Dashboard.
