# Claude Design Session Brief

## Objective

Use Claude Design to create the V2 AI BOT enterprise website design system while Claude Code is rate-limited.

This is design-only. Do not touch live bot, Redis, exchanges, deployment, or secrets.

## Product identity

AI BOT Enterprise Mission Control:
- serious, institutional, high-trust
- dark-mode-first
- animated but not distracting
- focused on signal lineage, risk, trainer health, symbol universe, and live safety

## Core pages

- Mission Control
- Symbol Universe
- Ingestor Health
- Feature Attribution
- Trainer GPU Health
- Prediction Worker Health
- Signal Explainability
- Risk Gateway
- Trader Fleet
- Paper / Shadow Trading
- Audit Ledger
- Agent Supervisor
- Claude / Codex / Ollama Activity
- Approval Center
- Live Readiness
- Public Landing
- Public Status
- Login / Step-up Auth

## Required visual concepts

- data flow: ingestors → features → trainer → signal → risk → trader
- risk gate default-deny banner
- live trading blocked indicator
- GPU trainer liveness panel
- symbol heatmap / ranking
- CoinAnk/Binance/Kuctoin/CoinAPI source freshness
- paper vs shadow vs legacy comparison
- audit timeline
- mobile/iPhone layout

## Animation requirements

Use tasteful animations:
- page transitions
- pulse health indicators
- flowing data-line animation
- risk-block animation
- symbol heatmap hover
- activity timeline
- mobile slide panels

Animations must never hide critical warnings.
