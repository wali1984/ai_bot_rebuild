## ROOT CAUSE (hypothesis — Codex must confirm file location)

The outcome_memory module writes the `block_reason` and `degraded=True` fields to Redis correctly.

The paper trading admission gate does NOT read these fields before accepting a signal. The admission gate may be checking different conditions (expected_move, spread, etc.) but NOT the outcome_memory block state.

Likely files to check:
- `v2/backend/app/paper_trading/` — paper signal admission function
- `v2/backend/app/strategy/` — strategy router admission gate
- `v2/backend/app/cli/v2_paper_*loop*.py` — main paper loop

Look for where `expected_move_after_cost_bps` is checked but NOT where `outcome_memory.degraded` is checked.

## MINIMAL FIX

In the paper trading admission gate (wherever signals are accepted/rejected before position opening):

```python
# BEFORE ACCEPTING ANY PAPER SIGNAL:
def should_reject_by_outcome_memory(symbol: str, timeframe: str) -> tuple[bool, str]:
    # Check global timeframe block
    all_key = f"v2:paper:outcome_memory:__ALL__:{timeframe}"
    all_om = redis.get(all_key)
    if all_om:
        om = json.loads(all_om)
        if om.get('degraded') and om.get('block_reason'):
            return True, f"TF_BLOCKED:{om['block_reason']}"
    
    # Check symbol-specific block
    sym_key = f"v2:paper:outcome_memory:{symbol}:{timeframe}"
    sym_om = redis.get(sym_key)
    if sym_om:
        om = json.loads(sym_om)
        if om.get('degraded') and om.get('block_reason'):
            return True, f"SYM_BLOCKED:{om['block_reason']}"
    
    return False, None

# In admission gate:
blocked, reason = should_reject_by_outcome_memory(symbol, timeframe)
if blocked:
    log_rejection(signal_id, reason)
    return REJECT
```
