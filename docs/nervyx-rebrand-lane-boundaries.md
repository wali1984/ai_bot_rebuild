current workspace is not isolated. The operator explicitly corrected the prior
approach and requested that this pass rebrand the existing app, keep the
existing local service on port `5173`, and avoid creating a new app. This pass
therefore stays in the current worktree and records the exception here.

No destructive Git command is permitted. In particular, this lane must not use
`git reset --hard`, `git clean -fd`, `git checkout -- .`, `git restore .`,
`git stash`, force push, or destructive rebase.
