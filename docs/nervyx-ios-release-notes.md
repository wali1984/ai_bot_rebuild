# NERVYX iOS Release Notes

NERVYX ONE rebrands the native companion app around Adaptive Market Intelligence. This build updates launch/login identity, app icons, module labels, and paper/read-only safety messaging while preserving existing backend authentication, typed API models, and live-trading blocks.

What to test:
- NERVYX ONE login and session persistence.
- Dashboard, signals, portfolio, paper, risk, monitor, alerts, and admin summaries.
- Paper/read-only safety labels and live-block messaging.
- Offline/stale data handling and decoding failures.
- Layout readability with Dynamic Type and VoiceOver.
